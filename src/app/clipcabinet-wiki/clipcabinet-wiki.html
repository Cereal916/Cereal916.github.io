Your first recording

  1. Record in Steam. Enable Steam Game Recording and capture some gameplay. ClipCabinet uses those existing recordings.
  2. Open ClipCabinet. Your videos are automatically imported into its library when the app opens. If the folder is not found, choose Settings → General → Recording folder and select your Steam recording folder.
  3. Double-click a clip. Watch it in the built-in player. Use the timeline to seek, or choose Export MP4 to make a shareable file.
Recorded something new? Click Refresh to rescan while ClipCabinet is open. Your original Steam recordings stay unchanged.

Meet your library

Steam handles recording. ClipCabinet adds tags, descriptions, search, and flexible views to help you organize the results. Saved clips and background recordings appear with their game and recording details.

What to try next

Add some context →Tags, descriptions, and favorites Share a moment →Original, H.264, HEVC, and AV1 export Find an answer →Setup, playback, and data questions
} @case ('organize') {

Add tags

  1. Right-click a clip and choose Tags.
  2. Find an existing tag, or type a new one and select Add. Paste comma-separated tags to add several at once.
  3. Click Save. Use the tag filter or search box to find matching clips later.

Use a few consistent labels: a game mode, a memorable moment, or something to review. Remove a tag with its × button.

Write a description

Right-click a clip, choose Description, write a short note, and save. Describe why the moment matters; descriptions appear in the library and can be searched.

Use favorites

Mark a clip as a favorite from its context menu or player. Enable Favorites only to narrow the library to your saved highlights.

Tags, descriptions, and favorites are stored separately from video files. See Back up and restore to protect them.
} @case ('browse') {

Search and filter

Type a game, tag, description, or recording type into Search clips. Combine the search with All games, All tags, Favorites only, or the timeline event filter.

Clear the search and reset the filters to see the full library again.

List, grid, and table

Choose your clip layout in Settings → General. List keeps notes visible, grid emphasizes thumbnails, and table makes it easy to compare details. Your annotations carry across all three views.

@for (view of views; track view.id) { }

Sort your library

Use the sort menu to choose Newest, Oldest, Largest, or Smallest. In table view, click a column header to sort by that column; resize or reorder columns to suit your workflow.

} @case ('playback') {

Open the player

Double-click a recording, or right-click it and choose Play. Use play/pause, the seek buttons, and the volume controls. Drag the timeline to seek; hold Shift while dragging for finer control.

Background sessions are grouped by game. For an active rolling recording, use Go live to move toward the latest available footage.

Timeline markers

Steam events, ranges, achievement markers, and game-suggested clips appear when the recording contains that data. Click a marker or an event card to jump to it. Use the event-type filter to focus on what you want.

Timeline shortcuts

With the timeline focused:

Key Action
Space Play or pause
← / → Seek back / forward 5 seconds
Page Down / Page Up Seek back / forward 30 seconds
Home / End Jump to the beginning / end
} @case ('export') {

Export in three steps

  1. Right-click a recording and choose Export MP4, or use Export MP4 in the player.
  2. Choose Original, H.264, HEVC, or AV1. For re-encoding, choose whether to use hardware encoding.
  3. Continue, choose the output file location in the Windows picker, and wait for the export to finish.

Choose a codec

Option Use it when…
Original You want the fastest export without video quality loss. It preserves the recording codec, so playback compatibility stays the same.
H.264 You want a widely supported format for sharing and playback.
HEVC / AV1 Your playback device supports the codec and you want to try a more efficient encoding format.

GPU or CPU encoding

Hardware encoding tries a compatible NVIDIA, Intel, or AMD GPU and automatically falls back to software if needed. Software encoding uses the CPU and can take longer. Size estimates are approximate.

Export creates a separate MP4; the original recording stays unchanged. If export fails, check free disk space and the output folder, then try H.264 or software encoding.
} @case ('settings') {

General settings

Open Settings → General to choose the recording folder, clip layout, and interface language. The app follows Steam’s language by default; your explicit language choice is remembered.

See the 15 supported languages

English, Simplified Chinese, Russian, Spanish (Spain), Portuguese (Brazil), German, Japanese, French, Polish, Korean, Traditional Chinese, Turkish, Thai, Spanish (Latin America), and Ukrainian.

Accessibility

Open the separate Settings → Accessibility tab. Changes apply immediately and are remembered.

  • Interface size: 100%, 110%, or 125% for larger text and controls.
  • Stronger contrast: clearer text and borders.
  • Reduce motion: fewer animations and still-image hover previews.
  • Disable hover previews: hide the library and timeline preview popups.

Use Tab and Shift + Tab to move through controls. Escape closes Settings.

Back up and restore

In Settings → General, choose Back up to save your favorites, descriptions, and tags as a JSON file. Use Import to restore it against the recordings in your current library.

Import replaces current annotations. ClipCabinet creates a safety backup first. Metadata backups do not include videos; back up your recordings separately.

Steam and privacy

Settings → Steam controls optional Steam Cloud annotation sync and friends-list activity. Cloud sync covers tags, descriptions, and favorites; video files stay local. Account and per-app Steam Cloud settings must also allow sync.

Each Steam account has its own annotations and saved recording folder. Restart ClipCabinet after switching accounts. Local browsing, playback, and export work without Steam running.

Friends-list activity is off by default. Enabling it shares a general organizing or exporting status, without clip names, recording paths, or annotation text.
