About the Studio

Founded in 2026, Slapcraft Games is an independent game studio creating 2D games that combine tactile play, strategic systems, pixel-art presentation, and modern twists on tabletop ideas.

Development includes AI-assisted tools. Slapcraft Games directs the game design, reviews and integrates generated output, tests each build, and makes the final creative and technical decisions.
